## چرا این پیاده‌سازی؟

سناریو از قرارداد موجود `Asset.Create` و مقادیر اعتبارسنجی‌شدهٔ HV-06 استفاده می‌کند. در موفقیت، نتیجه یک Asset دارد و برنامه ویژگی‌های عمومی آن را می‌خواند؛ در ورودی نامعتبر، فقط کد خطا چاپ می‌شود. آزمون‌های قبلی ساخت Asset، موفقیت، بازرسی مقادیر، خطاها و تقدم اعتبارسنجی شناسه را پوشش می‌دادند؛ بنابراین این PR کارخانه، سرویس یا مجموعه‌آزمون تکراری نساخت.

این انتخاب با محدودهٔ مرحله سازگار است: نمونهٔ کنسولی برای دیدن رفتار دامنه کافی است و از افزودن زودهنگام لایهٔ کاربرد یا ذخیره‌سازی پرهیز می‌کند. مستند، دادهٔ نمایشی را خیالی می‌داند؛ استفاده از نام‌های واقعی در خروجی یا لاگ می‌تواند اطلاعات حساس را افشا کند.

## گزینه‌ها و مرزهای دامنه

می‌شد برای ثبت، سرویس کاربردی، مخزن یا اتصال به Vault اضافه کرد، اما این‌ها در محدودهٔ HV-07 نبودند و در backlog جداگانه قرار دارند. در این PR «ثبت» فقط به معنای ساخت و بررسی شیء در همان فرایند است: چیزی ذخیره نمی‌شود و پس از پایان برنامه قابل‌بازیابی نیست. مالکیت و مجوز Vault، هماهنگی کاربردی و یکتایی سراسری شناسه هم بررسی نمی‌شوند.

PR دامنهٔ نام Asset را تغییر نمی‌دهد: نام معتبر عیناً حفظ می‌شود. خروجی موفق شناسه و نام را چاپ می‌کند، پس باید برای دادهٔ واقعی از نمونهٔ خیالی متفاوت رفتار کرد و اطلاعات حساس را وارد خروجی تشخیصی نکرد.

## ابزارها و بسته‌ها

این تغییر بسته یا وابستگی جدیدی اضافه نمی‌کند. از `Asset.Create` و آزمون‌های NUnit موجود استفاده می‌کند؛ آزمون جدیدی در diff این PR وجود ندارد. مستند HV-07 در زمان این PR به ۳۴ آزمون موجود (۷ معماری، ۱۱ ساخت Asset و ۱۶ value object) ارجاع می‌دهد.

## اعتبارسنجی و وضعیت فعلی

بررسی GitHub Actions با نام `Validate` موفق است؛ صفحهٔ Checks زمان ۳۸ ثانیه را نشان می‌دهد. توضیحات PR نیز موفقیت Restore، بررسی فرمت، ساخت Release بدون هشدار یا خطا، اجرای هر ۳۴ آزمون بدون آزمون ردشده، تطبیق خروجی Playground با خروجی مستند و `git diff --check` را گزارش می‌کنند. این فرمان‌ها در این بررسی دوباره اجرا نشده‌اند.

کد Playground در مخزن فعلی پس از HV-07 توسعه یافته و سناریوهای دیگری هم دارد؛ این گزارش فقط تغییرات و هدف diff خود PR شمارهٔ ۳۷ را توضیح می‌دهد. در نتیجه، نبود ذخیره‌سازی و دسترسی Vault در این PR محدودیت اعلام‌شدهٔ محدوده است، نه قابلیت ادعاشدهٔ این تغییر.
